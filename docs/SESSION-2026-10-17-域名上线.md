1. **免费 → 付费转向**：免费域名三条线（DigitalPlat 502 / eu.org 两周审核 / is-a.dev 不给改 NS）都有时间或硬伤；¥1 首年的 `.me` 是「今天上线」唯一解。eu.org 继续排队当零成本备用。

## 四、踩坑记录（下次直接抄答案）

| 坑 | 解法 |
|---|---|
| pnpm 12 因 `packageManager: pnpm@9.0.0` 自切换，本机 @pnpm/exe 二进制缺失 | 用系统 Node 24 跑 `node node_modules/@vinext/cloudflare/dist/cli.js deploy` |
| 托管 Node 22.22.2 构建报 PostCSS `load hook ... got null`（jiti 兼容） | 同上，Node 24（`C:\Program Files\nodejs\node.exe`） |
| vinext 部署报 `fetch failed` | wrangler OAuth token 约 1h 过期，先 `npx wrangler whoami` 静默刷新 |
| 阿里云改 NS 后注册局迟迟不生效 | 阿里云「DNS修改」页的「同步」按钮才是立即推送；查 `Resolve-DnsName -Server a0.nic.me -TcpOnly` |
| Cloudflare「Connect a custom domain」卡片无法自动化点击 | 直接 `PUT /accounts/{id}/workers/domains`（换绑加 `override_existing_origin: true`，否则 100116） |
| 新域名上 Turnstile 验证码会失败 | widget 的 domains 是白名单制，绑新域名必须同步加（`PUT /challenges/widgets/{sitekey}` 全量覆盖） |
| eu.org 注册用 Gmail 收不到验证信 | 必须用 163 等常规邮箱 |
| 本机 curl 直连新域名 DNS 报错但全球已生效 | 本机缓存滞后，`curl --resolve lifesandbox.me:443:104.21.48.110` 绕过 |
