## 七、2026-10-17 追加：登录修复 + 手机端首轮

**登录"请等待 30 秒"的根因**：新 Worker `lifesandbox` 没有任何运行时 secret（`wrangler secret list` 为空）。`rateLimit()` 在 try 块内调用 `getSupabaseClient()`，缺配置抛错后被 catch，生产环境走 fail-closed，返回 `retryAfter: 30`，文案即"请等待30 秒"。注册、登录全部中招。

**修复**：用户在项目根目录执行 `node scripts/set-cf-secrets.mjs`，9 个 secret 写入 `lifesandbox`（`AI_API_KEY` / `AI_API_URL` / `AI_MODEL` / `DEV_PASSWORD` / `MAIL_FROM` / `SESSION_SECRET` / `SUPABASE_URL` / `SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY` / `TURNSTILE_SECRET_KEY`，名单以 secret list 为准）。secret 写入会生成新 Worker 版本，无需重新部署。
