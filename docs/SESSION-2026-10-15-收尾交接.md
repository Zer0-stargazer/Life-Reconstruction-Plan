## 七、工程红线（踩过的坑）

**Windows PowerShell 5.1 下绝不要用 `Set-Content -Encoding utf8` 批量改源码**——会写入 BOM，导致 `pnpm build` 以 `3221225477`（`0xC0000005` 访问冲突）崩溃。用 Edit 工具，或：
```powershell
[System.IO.File]::WriteAllText($path, $text, (New-Object System.Text.UTF8Encoding($false)))
```

构建前确认 C 盘空间充足（本次因 C 盘写满导致过多次原生崩溃）。若 `ts-check` 报 `.next/types/validator.ts` 错误，先跑 `pnpm build` 生成类型。
