## 1. 先记住这是什么

这是一个 **Next.js 全栈 Web 应用**，不是阅读器，也不是传统算命工具，而是一个用数据、概率和规则帮助用户做人生决策的「人生作战室」。

核心产品结构：**8 个模块 + 1 条个性化时间轴**。

阅读路径：

```text
时间轴 ★ → 01 名字 → 02 职业 → 03 规律 → 04 窗口 → 05 努力 → 06 运气 → 07 命运 → 08 健康 → 回到时间轴
```

## 2. 接手第一步：先让静态页面跑起来

环境要求：Node.js >= 20.9，pnpm >= 9。

```bash
pnpm install
pnpm dev
```

浏览器打开：`http://localhost:5000`

只看静态页面时可以先不配置数据库；但以下能力必须配置 `.env.local` 才能用：登录、邀请码、开发者后台、内置 AI。

```bash
copy .env.example .env.local
```

需要的环境变量：

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `AI_API_URL`
- `AI_API_KEY`
- `AI_MODEL`
- `DEV_PASSWORD`
- `SESSION_SECRET`

数据库表结构：执行 `supabase/schema.sql`。

## 5. 改动前先看什么

1. 改模块顺序、编号、配色或首页导览：先看 `src/lib/module-identity.ts`。
2. 改窗口/职业/运气/规律数据：先确认 id 唯一、枚举值一致、解析格式不变。
3. 改登录、授权码、后台、**AI 额度**：先看 `src/lib/session.ts`、`src/lib/rate-limit.ts` 和对应 `src/app/api/` 路由。
4. 改 AI：先看 `src/lib/ai-stream.ts`、`src/lib/ai-providers.ts`、`src/lib/sse-client.ts`（客户端解析唯一入口）和 `src/app/api/ai/`。
5. 改页面头部或滚动进场：优先复用 `ModulePageHead`、`Reveal`、`fig-kit`，不要重新手写一套。
6. 改本地状态：优先使用 `usePersistedState`；localStorage 键名必须在 `src/lib/storage-keys.ts` 登记；
   不要在 SSR 首帧直接读取 localStorage。
7. **新增/改动锁定点（详情、AI、生成类动作）**：一律走 `useLockedAction().guard`，不要自己判断 user。
