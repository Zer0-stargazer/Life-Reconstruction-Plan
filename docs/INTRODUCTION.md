# 人生重构计划 - 项目介绍

## 一句话

用 AI 帮你做人生关键决策——从起名到择业, 从看命到改运。

## 这是什么

一个 AI 驱动的人生规划工具。不是鸡汤, 不是算命, 是用数据和逻辑帮你看见人生中那些看不见的规律和窗口。

8 个模块, 每个解决一个人生核心问题:

| 模块 | 解决什么 | 亮点 |
|---|---|---|
| **名字** | 起名/改名 | AI 生成, 文化底蕴 + 音韵学 |
| **职业** | 选什么行业 | 1535 个职业, 薪资/AI风险/自学路径 |
| **命运** | 我的天花板在哪 | 命势运三维报告, 看清先天牌面 |
| **规律** | 哪些规律在操纵我 | 8 维 288 条人生铁律 (衰老/通胀/黑天鹅...) |
| **努力** | 努力到底有没有用 | 6 维命运模拟器, 雷达图推演 |
| **窗口** | 什么时候该出手 | 473 个人生关键窗口, 当前窗口实时标亮 |
| **运气** | 运气能不能抓 | 250 个运气节点, 红利/暗门/黑天鹅 |
| **用户中心** | 我的进度和设置 | 角色管理、AI Key、人生阶段自定义 |

## 核心数据

> 2026-09-26 修订：数据已去重（原 4+7 组重名，见 KNOWN-ISSUES #9），以下为最终条目数

- **1535** 个职业（原 1539，已去重），覆盖 13 个行业，每个职业含薪资区间、AI 替代风险、自学推荐指数、课程/视频资源
- **288** 条人生铁律, 8 个维度 (宏观周期/生物衰老/心智带宽/社交吸血/习惯复利/黑天鹅/财富侵蚀/认知牢笼)
- **473** 个人生关键窗口（原 479，已去重）, 按年龄实时追踪"当前窗口"
- **250** 个运气节点, 含可控性分析和应对策略（另 50 条 redNodes 为未接线的预留数据）

## AI 能力

- 内置 AI 分析引擎, 各模块支持 AI 深度解读（依赖服务端 `.env.local` 配置 AI Key）
- 支持用户自带 API Key (8 个主流厂商)——**2026-09-26 已接入分析链路**（KNOWN-ISSUES #3）：
  在 /user 页选中某厂商后，各模块 AI 分析自动走用户自己的 Key
- SSE 流式输出, 打字机式实时渲染

## 用户体系

| 角色 | 权限 | 获取方式 |
|---|---|---|
| 普通用户 | 3 个开放模块 | 注册即得 |
| 充电用户 | 全部 7 个模块 | 邀请码升级 |
| 开发者 | 全模块 + 后台管理 | 开发者密码验证 |

## 设计风格

"人生作战室"——不是轻盈的消费级产品, 是沉稳的决策工具。

- 琥珀金主色调, 深岩灰基底
- grain 纹理背景, 卡片悬浮光影
- 衬线字体标题 + 等宽编号标签
- 微动效: 入场渐显、脉冲提示、按压反馈

## 技术栈

Next.js 16 + React 19 + TypeScript 5 + Tailwind CSS 4 + Supabase PostgreSQL + coze-coding-dev-sdk
