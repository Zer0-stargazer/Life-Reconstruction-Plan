# 人生重构计划 - 项目介绍

> 对外介绍版。最后修订 2026-10-01。

## 一句话

用 AI 帮你做人生关键决策——从起名到择业，从看命到改运。

## 这是什么

一个 AI 驱动的人生规划工具。不是鸡汤，不是算命，是用数据和逻辑帮你看见人生中那些看不见的规律和窗口。

**7 个模块 + 1 条个性化时间轴**，按顺序走一遍就是一次完整的自我盘点：

```
时间轴 ★ → 01 名字 → 02 职业 → 03 规律 → 04 窗口 → 05 努力 → 06 运气 → 07 命运 → ↺
```

| # | 模块 | 解决什么 | 亮点 |
|---|---|---|---|
| ★ | **时间轴** | 我这个年纪该看什么 | 拖年龄滑块 → 473 个窗口按「正在开启 / 已错过 / 尚未到来」分档；首页之外的第二入口 |
| 01 | **名字** | 起名/改名 | 笔画、音律、意象分析（本地生成，未接 AI） |
| 02 | **职业** | 选什么行业 | 757 个职业，薪资 / AI 风险 / 自学路径；含「黄金赛道 / 高危赛道」快看组 |
| 03 | **规律** | 哪些规律在操纵我 | 8 维 288 条人生铁律（衰老 / 通胀 / 黑天鹅…），每条含真实案例与应对策略 |
| 04 | **窗口** | 什么时候该出手 | 473 个人生关键窗口，含锁死力与错过代价 |
| 05 | **努力** | 努力到底有没有用 | 6 维命运模拟器，雷达图推演 + AI 策略 |
| 06 | **运气** | 运气能不能抓 | 250 个运气节点，标注影响度与可控度 |
| 07 | **命运** | 我的天花板在哪 | 命势运综合报告，看清先天牌面 |
| — | **用户中心** | 我的进度和设置 | 角色管理、AI Key、人生阶段自定义 |

## 核心数据

> 2026-10-01 实测。全站合计 **1,768 条**结构化数据，页面上的 `N=` 读数均为动态取值。

- **757** 个职业，覆盖 13 个行业，每个职业含薪资区间、AI 替代风险、自学推荐指数、课程/视频资源
  （2026-09-26 去重、09-28 移除 778 条机器生成模板条目后剩下 757 条真实条目）
- **288** 条人生铁律，8 个维度（宏观周期 / 生物衰老 / 心智带宽 / 社交吸血 / 习惯复利 / 黑天鹅 / 财富侵蚀 / 认知牢笼）
- **473** 个人生关键窗口，含锁死力等级、错过类型（永久/延迟/打折/收窄/涨价）、补救代价
- **250** 个运气节点，含可控性分析和应对策略

## AI 能力

- 内置 AI 分析引擎，各模块支持 AI 深度解读（依赖服务端 `.env.local` 配置 AI Key）
- **支持用户自带接入源**：任意 baseUrl + 协议（openai / claude / gemini / minimax）+ Key + 模型，
  在 /user 页添加、编辑、启停、测试、导入导出；各模块 AI 分析自动走用户自己的源。
  项目**不内置任何厂商地址与模型 id**
- SSE 流式输出，打字机式实时渲染
- 部分模块内置分析框架提示词（规律三按钮：破除之道 / 征兆识别 / 行动计划）

## 用户体系

| 角色 | 权限 | 获取方式 |
|---|---|---|
| 普通用户 | 3 个开放模块（名字 / 职业 / 窗口） | 注册即得 |
| 充电用户 | 全部模块 | 邀请码升级 |
| 开发者 | 全模块 + 后台管理 | 开发者密码验证 |

> 未登录访问受锁模块时显示登录引导；注册后普通用户可看 3 个基础模块。

## 设计风格

"人生作战室"——不是轻盈的消费级产品，是沉稳的决策工具。

- 琥珀金主色调，深岩灰基底（七个模块的图标各有自己的标识色，便于区分）
- grain 纹理背景，卡片悬浮光影
- 衬线字体标题 + 等宽编号标签
- 滚动进场渐显、脉冲提示、按压反馈；尊重「减少动态效果」系统偏好
- 站点图标：一条平铺轨迹在关键窗口处分叉跃升——「重构」的图形表达

## 技术栈

Next.js 16（App Router）+ React 19 + TypeScript 5 + Tailwind CSS 4 + Supabase PostgreSQL。
AI 走自写的 OpenAI-compatible SSE 客户端（`src/lib/ai-stream.ts`），无第三方 AI SDK。
图表全部手写 SVG，无图表库。
