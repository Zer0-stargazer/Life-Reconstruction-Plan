## 正式商业化模型（2026-10-02 起）

- **权限**：访客/普通用户 = 预览态（全模块列表可逛，详情弹层、AI 分析、报告生成锁定）；持码（premium）= 全解锁；developer = 全解锁 + 后台。
- **AI 额度**：授权码自带次数（/admin 建码时填，默认 200），兑换到账，内置 AI 每次分析扣 1，乐观锁防透支，流水在 `ai_credit_logs`；**用户自带 Key（BYOK）永久免费不扣额度**；developer 不限次。
- **发码**：/admin 单个/批量建码 → 用户加好友或邮件找开发者领码 → 解锁弹窗或 /user 页兑换。
- 未做（明确推迟）：在线支付、按 token 计费、免费模型兜底。

## 下一批 UI 工作

1. 建统一卡片体系  
   现在职业、窗口、运气、规律等页面各自一套小卡，层级太碎。  
   目标：每张卡一个主重点、一个主数据、少量辅助标签，不再满屏小字。

2. 每个模块定义主视觉  
   - 职业：薪资 / AI 风险 / 自学难度  
   - 窗口：年龄区间 / 错过代价  
   - 运气：影响幅度 / 可控度  
   - 规律：危险等级 / 挽回概率  
   - 命运：综合牌面

3. 降低长列表密度  
   保留折叠，但默认视图要更聚焦；不要一屏塞太多标签和小字。

4. 时间轴继续打磨  
   - 年龄滑块和分布曲线已经合成一个控制层，下一步检查移动端触控命中区域与曲线提示是否够用。  
   - 年度热度图继续观察真实使用反馈，避免变成“看起来好看但读不懂”。

## 下一批数据工作

1. 职业数量继续扩。
2. 学习资源必须从「分类级模板」升级为「职业级真实资源」。
3. 资源字段要拆开：书籍 / 课程 / 视频 / 文档 / 论坛 / 社区。
4. 资源必须可追溯，不再接受搜索页、平台首页这种伪资源。
