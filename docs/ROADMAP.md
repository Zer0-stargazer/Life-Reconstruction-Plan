# 当前路线图

> 更新时间：2026-10-01  
> 这份文档只记录「现在该做什么」和「临时策略什么时候收回」，不复述历史。

## 当前状态

- 项目已可运行：`pnpm validate`、`pnpm build` 均通过。
- 首页右侧已改为「你 → 七个模块」轨道图，不再复述下方模块卡。
- `/me` 时间轴已改成：年龄控制（内嵌全人生分布曲线）→ `±15 年` 年度热度图 → 聚焦区 → 明细清单。
- `/me` 已移除独立“全人生窗口密度”图表；分布信息由年龄滑块控制层承载，避免第一屏重复。
- `/me` 的 `±15 年窗口` 已改为按年份堆叠热度图，拖动年龄时视觉变化更明显。
- 测试期权限已临时放开：所有模块不要求登录 / 邀请码 / 开发者身份。

## 临时策略：必须回滚

| 项 | 位置 | 为什么临时放开 | 什么时候收回 |
|---|---|---|---|
| 全模块开放 | `src/contexts/auth-context.tsx` 的 `canAccessModule()` | 测试期方便逐页检查，不被登录/邀请码挡住 | 邀请码、权限、商业化链路开始收口前必须恢复按角色判断 |

恢复时：

1. `canAccessModule()` 重新按 `user`、`isPremium`、`NORMAL_USER_MODULES` 判断。
2. 侧栏锁定图标跟随 `ModuleLockIcon()` 自动恢复。
3. 文档里的「测试期全开放」要改成正式权限模型。

## 下一批 UI 工作

1. 建统一卡片体系  
   现在职业、窗口、运气、规律等页面各自一套小卡，层级太碎。  
   目标：每张卡一个主重点、一个主数据、少量辅助标签，不再满屏小字。

2. 每个模块定义主视觉  
   - 职业：薪资 / AI 风险 / 自学难度  
   - 窗口：年龄区间 / 错过代价  
   - 运气：影响幅度 / 可控度  
   - 规律：危险等级 / 挽回概率  
   - 命运：综合牌面

3. 降低长列表密度  
   保留折叠，但默认视图要更聚焦；不要一屏塞太多标签和小字。

4. 时间轴继续打磨  
   - 年龄滑块和分布曲线已经合成一个控制层，下一步检查移动端触控命中区域与曲线提示是否够用。  
   - 年度热度图继续观察真实使用反馈，避免变成“看起来好看但读不懂”。

## 下一批数据工作

1. 职业数量继续扩。
2. 学习资源必须从「分类级模板」升级为「职业级真实资源」。
3. 资源字段要拆开：书籍 / 课程 / 视频 / 文档 / 论坛 / 社区。
4. 资源必须可追溯，不再接受搜索页、平台首页这种伪资源。

## 文档规则

- 每次结构性改版，先更新 `00-优先阅读-项目接手.md`。
- 每次权限策略变化，先更新 `ARCHITECTURE.md` 和本文档。
- 修复完成后再更新 `KNOWN-ISSUES.md`，不要只写“应该没问题”。
