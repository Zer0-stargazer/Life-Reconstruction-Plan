按本项目 `CLAUDE.md` 里「项目命令」小节给出的命令，**依次**执行，不要跳步、不要自创新命令：

1. 类型检查
2. Lint（能自动修就自动修，剩下的手动改）
3. 单元测试
4. `git status --short` + `git diff --stat`，检查有没有改到无关文件

输出一张表：每步「通过 / 失败」+ 失败原因摘要（不超过 3 行）。

硬性要求：
- 第 3 步未通过，禁止输出「已完成」「全部通过」。
- 失败项要给出具体文件:行号，不要泛泛而谈。
